## Kenapa belajar ini?

Kakak makan $\frac{2}{8}$ kue, adik makan $\frac{3}{8}$ kue. Berapa bagian kue yang sudah dimakan? Berapa yang masih tersisa? Menjumlah dan mengurang pecahan membantu kamu menjawabnya.

## Analogi

Bayangkan **satu cokelat batangan** yang terbagi menjadi kotak-kotak kecil yang sama besar. Misalnya ada 7 kotak.

- Setiap kotak adalah $\frac{1}{7}$ cokelat.
- Kalau kamu mengambil 2 kotak, lalu mengambil 3 kotak lagi, kamu punya 5 kotak.
- **Ukuran kotaknya tidak berubah.** Tetap $\frac{1}{7}$ per kotak.

Jadi yang kita jumlahkan adalah **banyak kotak** (pembilang). Ukuran kotak (penyebut) tetap.

## Konsep

### Menjumlah pecahan senama

Pecahan senama punya penyebut sama. Jumlahkan pembilangnya saja. Penyebutnya tetap.

$$\frac{2}{7} + \frac{3}{7} = \frac{5}{7}$$

2 kotak + 3 kotak = 5 kotak. Kotaknya tetap berukuran $\frac{1}{7}$.

### Mengurang pecahan senama

Kurangkan pembilangnya saja. Penyebutnya tetap.

$$\frac{6}{7} - \frac{4}{7} = \frac{2}{7}$$

### Satu utuh

Satu cokelat utuh berisi semua kotaknya. Kalau ada 7 kotak, satu utuh sama dengan $\frac{7}{7}$.

$$1 = \frac{2}{2} = \frac{5}{5} = \frac{7}{7} = \frac{12}{12}$$

### Menggenapkan menjadi 1 utuh

Berapa yang kurang agar menjadi 1 utuh? Hitung kotak yang belum ada.

Kalau kamu punya $\frac{5}{7}$, masih kurang 7 − 5 = 2 kotak. Jadi $\frac{5}{7} + \frac{2}{7} = 1$.

Di materi ini, semua hasil tetap di dalam satu keseluruhan. Hasilnya tidak lebih dari 1.

## Contoh langkah demi langkah

### Contoh 1: Menjumlah

**Soal.** $\frac{2}{7} + \frac{3}{7} = ...$

1. **Langkah 1: Cek penyebut.** Keduanya 7. Pecahan senama, jadi bisa langsung dijumlah.
2. **Langkah 2: Jumlahkan banyak kotak.** Pembilang 2 + 3 = 5.
3. **Langkah 3: Tulis hasil.** Penyebut tetap 7. Hasilnya $\frac{5}{7}$.
4. **Cek jawaban.** Gambar cokelatnya.

```
2/7  | X | X |   |   |   |   |   |
3/7  | X | X | X |   |   |   |   |
5/7  | X | X | X | X | X |   |   |
```

2 kotak dan 3 kotak menjadi 5 kotak. Benar.

**Jawaban:** $\frac{5}{7}$.

### Contoh 2: Mengurang

**Soal.** $\frac{8}{11} - \frac{3}{11} = ...$

1. **Langkah 1: Cek penyebut.** Keduanya 11. Pecahan senama.
2. **Langkah 2: Kurangkan banyak kotak.** Punya 8 kotak, diambil 3 kotak. 8 − 3 = 5.
3. **Langkah 3: Tulis hasil.** Penyebut tetap 11. Hasilnya $\frac{5}{11}$.
4. **Cek jawaban.** Jumlahkan balik: $\frac{5}{11} + \frac{3}{11} = \frac{8}{11}$. Benar.

**Jawaban:** $\frac{5}{11}$.

### Contoh 3: Menggenapkan dan mengurang dari 1

**Soal.** (a) $\frac{5}{12} + ... = 1$. (b) $1 - \frac{3}{5} = ...$

1. **Langkah 1: Ubah 1 utuh (a).** Penyebutnya 12. Jadi 1 utuh = $\frac{12}{12}$.
2. **Langkah 2: Hitung kotak yang kurang (a).** 12 − 5 = 7. Jadi yang kurang $\frac{7}{12}$.
3. **Langkah 3: Ubah 1 utuh (b).** Penyebutnya 5. Jadi 1 = $\frac{5}{5}$.
4. **Langkah 4: Kurangkan (b).** $\frac{5}{5} - \frac{3}{5} = \frac{2}{5}$.
5. **Cek jawaban.** (a) $\frac{5}{12} + \frac{7}{12} = \frac{12}{12} = 1$. (b) $\frac{2}{5} + \frac{3}{5} = \frac{5}{5} = 1$. Keduanya benar.

**Jawaban:** (a) $\frac{7}{12}$. (b) $\frac{2}{5}$.

### Contoh 4: Soal cerita dua langkah

**Soal.** Ibu membuat 1 loyang kue. Kue dipotong 8 bagian sama besar. Budi makan $\frac{2}{8}$ kue. Siti makan $\frac{3}{8}$ kue. Berapa bagian kue yang dimakan mereka berdua? Berapa bagian yang tersisa?

1. **Langkah 1: Pahami soal.** Ada dua pertanyaan. Pertama, jumlah yang dimakan. Kedua, sisa dari 1 loyang.
2. **Langkah 2: Jumlahkan yang dimakan.** $\frac{2}{8} + \frac{3}{8}$. Pembilang 2 + 3 = 5. Jadi $\frac{5}{8}$.
3. **Langkah 3: Ubah 1 loyang.** 1 loyang = $\frac{8}{8}$.
4. **Langkah 4: Hitung sisa.** $\frac{8}{8} - \frac{5}{8} = \frac{3}{8}$.
5. **Cek jawaban.** Yang dimakan ditambah sisa harus 1 loyang. $\frac{5}{8} + \frac{3}{8} = \frac{8}{8} = 1$. Benar.

```
Budi  | X | X |   |   |   |   |   |   |
Siti  |   |   | X | X | X |   |   |   |
Sisa  |   |   |   |   |   | X | X | X |
```

**Jawaban:** Dimakan $\frac{5}{8}$ kue, tersisa $\frac{3}{8}$ kue.

## Kesalahan yang sering terjadi

- **Menjumlah penyebut juga.** $\frac{2}{7} + \frac{3}{7}$ dijawab $\frac{5}{14}$. Ukuran kotak cokelat tidak berubah saat kamu mengambil lebih banyak. Penyebut tetap 7, jadi $\frac{5}{7}$.
- **Mengurang penyebut juga.** $\frac{8}{11} - \frac{3}{11}$ dijawab $\frac{5}{0}$. Penyebut tetap 11. Jawabannya $\frac{5}{11}$.
- **Lupa mengubah 1 menjadi pecahan.** $1 - \frac{3}{5}$ dihitung 3 − 1 atau 1 − 3. Ubah dulu 1 menjadi $\frac{5}{5}$, lalu 5 − 3 = 2.
- **Salah menghitung yang kurang.** $\frac{5}{12} + ... = 1$ dijawab $\frac{5}{12}$ atau $\frac{1}{12}$. Hitung kotak yang belum ada: 12 − 5 = 7.

## Ringkasan

- Pecahan senama: penyebutnya sama, ukuran kotaknya sama.
- Menjumlah: jumlahkan pembilang, penyebut tetap.
- Mengurang: kurangkan pembilang, penyebut tetap.
- Satu utuh = penyebut per penyebut, misalnya $1 = \frac{8}{8}$.
- Menggenapkan: kotak yang kurang = penyebut − pembilang.
- Cek: hasil kurang + yang diambil = yang semula.

## Cek pemahaman

1. $\frac{1}{6} + \frac{4}{6} = ...$
2. $\frac{11}{12} - \frac{4}{12} = ...$
3. $\frac{3}{9} + \frac{4}{9} = ...$
4. $\frac{2}{5} + ... = 1$
5. Made punya 1 gulung pita yang dipotong 10 bagian sama panjang. Ia memakai $\frac{3}{10}$ pita untuk kado dan $\frac{4}{10}$ pita untuk hiasan. Berapa bagian pita yang tersisa?

### Kunci jawaban

1. $\frac{5}{6}$. Pembilang 1 + 4 = 5, penyebut tetap 6.
2. $\frac{7}{12}$. Pembilang 11 − 4 = 7, penyebut tetap 12.
3. $\frac{7}{9}$. Pembilang 3 + 4 = 7, penyebut tetap 9.
4. $\frac{3}{5}$. Satu utuh adalah $\frac{5}{5}$, dan 5 − 2 = 3.
5. $\frac{3}{10}$. Dipakai $\frac{3}{10} + \frac{4}{10} = \frac{7}{10}$, sisa $\frac{10}{10} - \frac{7}{10} = \frac{3}{10}$.
