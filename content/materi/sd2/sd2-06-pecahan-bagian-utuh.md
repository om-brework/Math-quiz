## Kenapa belajar ini?

Ayah membeli satu martabak, lalu memotongnya untuk keluarga. Berapa bagian yang kamu makan? Pecahan dipakai untuk menyebut bagian dari satu benda utuh.

## Analogi

Bayangkan **satu martabak manis** berbentuk persegi panjang. Martabak itu dipotong menjadi beberapa potong yang **sama besar**.

- Banyak potongan seluruhnya menjadi **penyebut** (angka bawah).
- Banyak potongan yang kamu ambil menjadi **pembilang** (angka atas).

Kalau martabak dipotong 4 sama besar dan kamu makan 1 potong, kamu makan $\frac{1}{4}$ martabak.

## Konsep

### Pembilang dan penyebut

$$\frac{3}{4}$$

- **4** adalah penyebut: martabak dipotong menjadi 4 bagian sama besar.
- **3** adalah pembilang: ada 3 bagian yang diambil atau diarsir.

$\frac{3}{4}$ dibaca "tiga per empat" atau "tiga perempat".

Ingat: potongan **harus sama besar**. Kalau tidak sama besar, itu bukan pecahan.

### Menggambar pecahan

Untuk menggambar $\frac{3}{8}$:

1. Gambar satu persegi panjang. Itu satu martabak utuh.
2. Bagi menjadi 8 bagian sama besar. Angka 8 dari penyebut.
3. Arsir 3 bagian. Angka 3 dari pembilang.

```
+---+---+---+---+---+---+---+---+
| X | X | X |   |   |   |   |   |
+---+---+---+---+---+---+---+---+
```

Bagian berisi X adalah bagian yang diarsir.

### Pecahan satuan

Pecahan dengan pembilang 1 disebut **pecahan satuan**. Contoh: $\frac{1}{2}$, $\frac{1}{5}$, $\frac{1}{12}$.

Semakin banyak potongan, semakin kecil tiap potongan. Martabak untuk 2 orang potongannya besar. Martabak yang sama untuk 8 orang potongannya kecil.

```
1/2  |       X       |               |
1/4  |   X   |       |       |       |
1/8  | X |   |   |   |   |   |   |   |
```

Jadi untuk pecahan satuan: **penyebut lebih besar, pecahan lebih kecil**. $\frac{1}{2} > \frac{1}{4} > \frac{1}{8}$.

### Pecahan senama

Pecahan senama punya **penyebut yang sama**. Contoh: $\frac{2}{9}$ dan $\frac{5}{9}$.

Ukuran potongannya sama. Jadi cukup bandingkan banyak potongan. **Pembilang lebih besar, pecahan lebih besar**. $\frac{5}{9} > \frac{2}{9}$.

Dalam materi ini, penyebutnya sampai 12.

## Contoh langkah demi langkah

### Contoh 1: Menulis pecahan dari gambar

**Soal.** Tulis pecahan untuk bagian yang diarsir dan yang tidak diarsir.

```
+---+---+---+---+---+
| X | X |   |   |   |
+---+---+---+---+---+
```

1. **Langkah 1: Hitung semua bagian.** Ada 5 bagian sama besar. Penyebutnya 5.
2. **Langkah 2: Hitung bagian yang diarsir.** Ada 2 bagian. Pembilangnya 2. Jadi $\frac{2}{5}$.
3. **Langkah 3: Hitung bagian yang tidak diarsir.** 5 − 2 = 3 bagian. Jadi $\frac{3}{5}$.
4. **Cek jawaban.** 2 bagian + 3 bagian = 5 bagian, sama dengan semua bagian. Benar.

**Jawaban:** Diarsir $\frac{2}{5}$, tidak diarsir $\frac{3}{5}$.

### Contoh 2: Membandingkan pecahan satuan

**Soal.** Mana yang lebih besar, $\frac{1}{4}$ atau $\frac{1}{6}$?

1. **Langkah 1: Kenali jenis pecahan.** Keduanya punya pembilang 1. Ini pecahan satuan.
2. **Langkah 2: Bayangkan martabak.** $\frac{1}{4}$ berarti 1 potong dari martabak yang dibagi 4 orang. $\frac{1}{6}$ berarti 1 potong dari martabak yang sama, dibagi 6 orang.
3. **Langkah 3: Bandingkan.** Dibagi ke lebih sedikit orang, potongannya lebih besar. Jadi $\frac{1}{4}$ lebih besar.
4. **Cek jawaban.** Gambar dua batang yang sama panjang.

```
1/4  |  X  |     |     |     |
1/6  | X |   |   |   |   |   |
```

Bagian $\frac{1}{4}$ memang lebih panjang. Benar.

**Jawaban:** $\frac{1}{4} > \frac{1}{6}$.

### Contoh 3: Mengurutkan pecahan

**Soal.** (a) Urutkan dari yang terkecil: $\frac{5}{9}$, $\frac{2}{9}$, $\frac{7}{9}$, $\frac{4}{9}$. (b) Urutkan dari yang terbesar: $\frac{1}{3}$, $\frac{1}{12}$, $\frac{1}{7}$, $\frac{1}{2}$.

1. **Langkah 1: Kenali jenis pecahan (a).** Semua penyebutnya 9. Ini pecahan senama. Potongannya sama besar.
2. **Langkah 2: Urutkan pembilang (a).** 2, 4, 5, 7. Jadi $\frac{2}{9}$, $\frac{4}{9}$, $\frac{5}{9}$, $\frac{7}{9}$.
3. **Langkah 3: Kenali jenis pecahan (b).** Semua pembilangnya 1. Ini pecahan satuan.
4. **Langkah 4: Urutkan penyebut (b).** Yang terbesar punya penyebut terkecil. Penyebut dari kecil ke besar: 2, 3, 7, 12. Jadi $\frac{1}{2}$, $\frac{1}{3}$, $\frac{1}{7}$, $\frac{1}{12}$.
5. **Cek jawaban.** Martabak untuk 2 orang potongannya paling besar. Martabak untuk 12 orang potongannya paling kecil. Sesuai.

**Jawaban:** (a) $\frac{2}{9}$, $\frac{4}{9}$, $\frac{5}{9}$, $\frac{7}{9}$. (b) $\frac{1}{2}$, $\frac{1}{3}$, $\frac{1}{7}$, $\frac{1}{12}$.

### Contoh 4: Soal cerita

**Soal.** Ibu memotong kue bolu menjadi 10 bagian sama besar. Made makan 3 potong. Putu makan 2 potong. Tulis pecahan bagian yang dimakan masing-masing. Siapa yang makan lebih banyak?

1. **Langkah 1: Cari penyebut.** Kue dipotong 10 bagian sama besar. Penyebutnya 10.
2. **Langkah 2: Tulis pecahan.** Made: $\frac{3}{10}$. Putu: $\frac{2}{10}$.
3. **Langkah 3: Bandingkan.** Penyebutnya sama, jadi bandingkan pembilang. 3 lebih dari 2. Jadi $\frac{3}{10} > \frac{2}{10}$.
4. **Cek jawaban.** Gambar kuenya.

```
Made  | X | X | X |   |   |   |   |   |   |   |
Putu  | X | X |   |   |   |   |   |   |   |   |
```

Bagian Made lebih panjang. Benar.

**Jawaban:** Made makan $\frac{3}{10}$, Putu makan $\frac{2}{10}$. Made makan lebih banyak.

## Kesalahan yang sering terjadi

- **Potongan tidak sama besar.** Satu kue dipotong 4 tetapi ukurannya beda-beda, lalu satu potong disebut $\frac{1}{4}$. Pecahan hanya berlaku untuk bagian yang sama besar.
- **Mengira penyebut besar berarti pecahan besar.** Menganggap $\frac{1}{8} > \frac{1}{4}$ karena 8 > 4. Ingat martabak: dibagi 8 orang, potongannya lebih kecil.
- **Penyebut diisi bagian yang tidak diarsir.** Ada 2 bagian diarsir dari 5, lalu ditulis $\frac{2}{3}$. Penyebut adalah **semua** bagian, yaitu 5. Jadi $\frac{2}{5}$.
- **Pembilang dan penyebut tertukar.** Menulis $\frac{5}{2}$ untuk 2 bagian dari 5. Bagian yang diambil selalu di atas.

## Ringkasan

- Pecahan menyebut bagian dari satu benda utuh yang dipotong sama besar.
- Penyebut (bawah) = banyak bagian seluruhnya. Pembilang (atas) = banyak bagian yang diambil.
- Menggambar pecahan: bagi sesuai penyebut, arsir sesuai pembilang.
- Pecahan satuan: penyebut lebih besar, pecahan lebih kecil.
- Pecahan senama: pembilang lebih besar, pecahan lebih besar.

## Cek pemahaman

1. Sebuah batang dibagi 7 bagian sama besar. Ada 4 bagian diarsir. Tulis pecahan bagian yang diarsir dan yang tidak diarsir.
2. Isi dengan > atau <: $\frac{1}{5}$ ... $\frac{1}{9}$.
3. Isi dengan > atau <: $\frac{7}{11}$ ... $\frac{9}{11}$.
4. Urutkan dari yang terkecil: $\frac{1}{4}$, $\frac{1}{10}$, $\frac{1}{2}$, $\frac{1}{6}$.
5. Sebuah pita dipotong menjadi 12 bagian sama panjang. Siti mengambil 5 bagian. Putu mengambil 7 bagian. Tulis pecahannya. Siapa yang mengambil lebih banyak?

### Kunci jawaban

1. Diarsir $\frac{4}{7}$, tidak diarsir $\frac{3}{7}$, karena 7 − 4 = 3.
2. $\frac{1}{5} > \frac{1}{9}$. Dibagi 5 bagian, potongannya lebih besar daripada dibagi 9.
3. $\frac{7}{11} < \frac{9}{11}$. Penyebutnya sama, dan 7 kurang dari 9.
4. $\frac{1}{10}$, $\frac{1}{6}$, $\frac{1}{4}$, $\frac{1}{2}$. Penyebut terbesar adalah pecahan satuan terkecil.
5. Siti $\frac{5}{12}$, Putu $\frac{7}{12}$. Putu lebih banyak, karena 7 lebih dari 5.
