## Kenapa belajar ini?

Segitiga ada di mana-mana: kuda-kuda atap rumah, rangka jembatan, dan penyangga rak. Segitiga kuat karena bentuknya tidak mudah berubah. Dengan mengenal sifat-sifatnya, kamu bisa menghitung sudut yang belum diketahui.

## Analogi

Ambil **segitiga dari kertas**. Warnai ketiga sudutnya, lalu **sobek** ketiga ujung sudut itu. Jajarkan ketiga sobekan sehingga ujung-ujungnya bertemu di satu titik.

Apa yang terjadi? Ketiga sobekan selalu membentuk **garis lurus**. Dari materi sebelumnya, sudut pada garis lurus adalah $180^\circ$, atau **setengah pizza**. Jadi jumlah tiga sudut segitiga **selalu** $180^\circ$, berapa pun bentuk dan ukuran segitiganya.

Setiap kali mencari sudut segitiga, bayangkan tiga sobekan itu harus pas membentuk garis lurus.

## Konsep

### Jumlah sudut segitiga

$$\angle A + \angle B + \angle C = 180^\circ$$

Jika dua sudut diketahui, sudut ketiga $= 180^\circ -$ (jumlah dua sudut itu).

### Segitiga siku-siku

Salah satu sudutnya $90^\circ$ (ditandai kotak kecil). Dua sudut lainnya jumlahnya $180^\circ - 90^\circ = 90^\circ$.

```
  A
  |\
  | \
  |  \
  |_  \
  |_|__\
  B     C
```

### Segitiga sama kaki

- **Dua sisi sama panjang** (ditandai garis kecil yang sama).
- **Dua sudut alas sama besar.** Sudut alas adalah sudut di ujung sisi ketiga, yang berhadapan dengan sisi-sisi yang sama panjang.
- Sudut di antara dua sisi yang sama disebut **sudut puncak**.

```
        P
       / \
   -  /   \  -
     /     \
    Q-------R
```

PQ = PR, jadi $\angle Q = \angle R$.

### Segitiga sama sisi

- **Ketiga sisi sama panjang.**
- **Ketiga sudut sama besar**, masing-masing $180^\circ \div 3 = 60^\circ$.

### Sudut di luar segitiga

Jika satu sisi segitiga diperpanjang, sudut di luar dan sudut di dalam yang bersebelahan berada pada **garis lurus**, jadi jumlahnya $180^\circ$.

## Contoh langkah demi langkah

### Contoh 1: Dua sudut diketahui

**Soal.** Pada segitiga ABC, $\angle A = 48^\circ$ dan $\angle B = 67^\circ$. Hitung $\angle C$.

1. **Langkah 1: Pakai jumlah sudut segitiga.** Tiga sobekan sudut harus membentuk $180^\circ$.
2. **Langkah 2: Jumlahkan yang diketahui.** $48^\circ + 67^\circ = 115^\circ$.
3. **Langkah 3: Kurangkan.** $\angle C = 180^\circ - 115^\circ = 65^\circ$.
4. **Cek jawaban.** $48^\circ + 67^\circ + 65^\circ = 180^\circ$. Benar.

**Jawaban:** $\angle C = 65^\circ$.

### Contoh 2: Segitiga siku-siku

**Soal.** Segitiga ABC siku-siku di B. $\angle A = 34^\circ$. Hitung $\angle C$.

1. **Langkah 1: Tulis sudut yang diketahui.** $\angle B = 90^\circ$ (siku-siku) dan $\angle A = 34^\circ$.
2. **Langkah 2: Jumlahkan.** $90^\circ + 34^\circ = 124^\circ$.
3. **Langkah 3: Kurangkan.** $\angle C = 180^\circ - 124^\circ = 56^\circ$.
4. **Cek jawaban.** Dua sudut lancip pada segitiga siku-siku jumlahnya $90^\circ$: $34^\circ + 56^\circ = 90^\circ$. Benar.

**Jawaban:** $\angle C = 56^\circ$.

### Contoh 3: Segitiga sama kaki

**Soal.** Segitiga PQR sama kaki dengan PQ = PR (gambar di atas). (a) Jika $\angle P = 40^\circ$, hitung $\angle Q$ dan $\angle R$. (b) Jika $\angle Q = 52^\circ$, hitung $\angle P$.

1. **Langkah 1: Kenali sudut alas.** PQ = PR, jadi sudut alasnya $\angle Q$ dan $\angle R$, dan keduanya sama besar.
2. **Langkah 2 (a): Cari jumlah dua sudut alas.** $180^\circ - 40^\circ = 140^\circ$.
3. **Langkah 3 (a): Bagi dua.** $140^\circ \div 2 = 70^\circ$. Jadi $\angle Q = \angle R = 70^\circ$.
4. **Langkah 4 (b): Dua sudut alas.** $\angle Q = \angle R = 52^\circ$, jumlahnya $104^\circ$.
5. **Langkah 5 (b): Cari sudut puncak.** $\angle P = 180^\circ - 104^\circ = 76^\circ$.
6. **Cek jawaban.** (a) $40^\circ + 70^\circ + 70^\circ = 180^\circ$. (b) $76^\circ + 52^\circ + 52^\circ = 180^\circ$. Keduanya benar.

**Jawaban:** (a) $\angle Q = \angle R = 70^\circ$. (b) $\angle P = 76^\circ$.

### Contoh 4: Sisi diperpanjang

**Soal.** Segitiga ABC sama kaki dengan AB = AC. Sisi BC diperpanjang sampai titik D, sehingga B, C, D segaris. $\angle ACD = 115^\circ$. Hitung $\angle BAC$.

```
        A
       / \
      /   \
     /     \
    B-------C---------D
```

1. **Langkah 1: Pakai garis lurus.** $\angle ACB$ dan $\angle ACD$ berada pada garis lurus BD. $\angle ACB = 180^\circ - 115^\circ = 65^\circ$.
2. **Langkah 2: Pakai sifat sama kaki.** AB = AC, jadi sudut alas $\angle ABC = \angle ACB = 65^\circ$.
3. **Langkah 3: Pakai jumlah sudut segitiga.** $\angle BAC = 180^\circ - 65^\circ - 65^\circ = 50^\circ$.
4. **Cek jawaban.** $50^\circ + 65^\circ + 65^\circ = 180^\circ$, dan $65^\circ + 115^\circ = 180^\circ$. Semua cocok.

**Jawaban:** $\angle BAC = 50^\circ$.

### Contoh 5: Soal cerita kuda-kuda atap

**Soal.** Pak Ketut membuat kuda-kuda atap berbentuk segitiga sama kaki. Sudut di puncak atap $110^\circ$. Berapa besar sudut kemiringan di kedua ujung bawah atap?

```
|<------------------ 180 derajat ------------------->|
|          puncak 110          |    ?     |    ?     |
```

1. **Langkah 1: Pahami soal.** Segitiga sama kaki: dua ujung bawah adalah sudut alas yang sama besar.
2. **Langkah 2: Cari jumlah dua sudut alas.** $180^\circ - 110^\circ = 70^\circ$.
3. **Langkah 3: Bagi dua.** $70^\circ \div 2 = 35^\circ$.
4. **Cek jawaban.** $110^\circ + 35^\circ + 35^\circ = 180^\circ$. Benar.

**Jawaban:** Setiap ujung bawah membentuk sudut $35^\circ$.

## Kesalahan yang sering terjadi

- **Memakai 360° untuk segitiga.** Tiga sobekan sudut membentuk garis lurus, bukan satu putaran. Jumlahnya $180^\circ$.
- **Salah memilih sudut yang sama.** Pada segitiga sama kaki, yang sama adalah **sudut alas** (di ujung sisi ketiga), bukan sudut puncak dengan sudut alas.
- **Lupa membagi dua.** Pada contoh 3(a), menjawab $\angle Q = 140^\circ$. Angka $140^\circ$ adalah jumlah dua sudut alas, jadi masih harus dibagi 2.
- **Lupa sudut siku-siku.** Pada segitiga siku-siku, $90^\circ$ juga harus ikut dijumlahkan, meskipun hanya ditandai kotak kecil.
- **Segitiga dengan dua sudut tumpul atau dua siku-siku.** Ini tidak mungkin, karena dua sudut itu saja sudah $180^\circ$ atau lebih. Jika hasil hitunganmu seperti itu, periksa kembali.

## Ringkasan

- Jumlah ketiga sudut segitiga selalu $180^\circ$.
- Segitiga siku-siku: satu sudut $90^\circ$, dua sudut lain jumlahnya $90^\circ$.
- Segitiga sama kaki: dua sisi sama panjang, dua sudut alas sama besar.
- Segitiga sama sisi: tiga sisi sama panjang, setiap sudut $60^\circ$.
- Sudut di luar dan sudut di dalam pada sisi yang diperpanjang jumlahnya $180^\circ$.

## Cek pemahaman

1. Dua sudut sebuah segitiga $75^\circ$ dan $38^\circ$. Hitung sudut ketiga.
2. Sebuah segitiga siku-siku punya satu sudut $29^\circ$. Hitung sudut lancip yang lain.
3. Segitiga sama kaki punya sudut alas $64^\circ$. Hitung sudut puncaknya.
4. Segitiga sama kaki punya sudut puncak $96^\circ$. Hitung setiap sudut alasnya.
5. Segitiga ABC sama sisi. Sisi BC diperpanjang sampai D. Hitung $\angle ACD$.

### Kunci jawaban

1. $67^\circ$. $180^\circ - (75^\circ + 38^\circ) = 180^\circ - 113^\circ = 67^\circ$.
2. $61^\circ$. $90^\circ - 29^\circ = 61^\circ$.
3. $52^\circ$. $180^\circ - (64^\circ + 64^\circ) = 180^\circ - 128^\circ = 52^\circ$.
4. $42^\circ$. $(180^\circ - 96^\circ) \div 2 = 84^\circ \div 2 = 42^\circ$.
5. $120^\circ$. $\angle ACB = 60^\circ$ (sama sisi), jadi $\angle ACD = 180^\circ - 60^\circ = 120^\circ$.
